# 有赞实时换装

本地运行的摄像头实时试衣应用。PC 和手机均采用全高大画面 + 右侧窄衣橱，控制按钮浮在画面下角。使用 Xmax 中国区 X2.1 和官方 `@xmaxai/web-sdk` 1.1.3。

## 直接使用

依赖已安装，用户提供的 API Key 已放入本地 `.env`，没有写进前端源码。

1. 双击「启动有赞实时换装.command」，保持终端窗口运行。
2. PC 用 Chrome / Edge 打开 `http://localhost:5173`。
3. 点「开启摄像头」，允许摄像头。此时只有本地预览，不连接 Xmax。
4. 选择服饰，再点「开始试衣」。实际换装首帧显示后才倒计时，默认 15 秒，可选 10 / 30 秒。等待首帧单独限时 20 秒，等待也可能产生 Xmax 费用。
5. 在试衣期间点另一件服饰，实时更新参考图；时长不会因换衣重新计算。快速点选会合并为最新选择。
6. 点「停止试衣」或到达设定时长，关闭实时会话并停用临时密钥。切换后台也会自动停止。不会自动重试付费生成。

裤装需要让下半身入镜，鞋子需要双脚完整入镜。每次选择替换一个品类，不承诺累积多件穿搭；换装效果取决于模型，鞋履、复杂遮挡和转身尤其需要用户亲测。

## 手机使用（局域网）

手机与电脑连接同一个 Wi-Fi，电脑持续运行服务，也需要能够访问 Xmax 的网络。页面通过局域网访问，AI 仍由 Xmax 云端处理。

手机摄像头必须在可信 HTTPS 页面使用，普通 `http://192.168...` 不能打开摄像头。因此项目在本机生成独立的 HTTPS 证书，监听 3443 端口；不会自动修改电脑或手机的系统信任设置。

1. 服务首次启动后，项目文件夹会出现「有赞实时换装-手机证书.cer」。通过隔空投送或文件传输将它发到手机。
2. iPhone：安装证书描述文件（设置 → 通用 → VPN 与设备管理 / 已下载的描述文件），然后进入「设置 → 通用 → 关于本机 → 证书信任设置」，为 **Youzan Local Try-On CA** 启用完全信任。
3. Android：在系统的安全 / 加密与凭据设置里安装 CA 证书。各品牌入口不同，使用 Chrome 打开页面；部分设备或组织策略可能不允许用户 CA。
4. 在电脑页面点「手机访问」，扫码获取带配对信息的 HTTPS 局域网地址，用 Safari 或 Chrome 打开。如果出现证书错误，先检查证书是否正确安装与信任，不要关闭浏览器安全保护。
5. 如果电脑有多个网卡，在弹窗中选择与手机同一 Wi-Fi 网段的地址。首次运行若系统询问 Node.js 的本地网络访问，请允许。

证书有效期为 30 天。测试结束可从手机移除。到期后停止服务，移除项目 `.local/` 内旧证书并重新启动，再安装新证书。换 Wi-Fi / IP 后重启服务，服务会重新签发匹配当前 IP 的服务器证书。

## 配置与运行

需要 Node.js 20+、npm，以及 `openssl`（macOS 一般已提供）。其他电脑先安装依赖：

```sh
npm install --no-audit --no-fund --ignore-scripts
npm start
```

`.env` 支持 `XMAX_API_KEY`、`PORT`（默认 5173）、`HTTPS_PORT`（默认 3443）。更换 Key 后重启。没有构建步骤，Vite 以开发中间件方式提供本地页面。不要将此开发服务器直接用于公网生产服务。

PC HTTP 只监听回环地址；手机 HTTPS 监听局域网，扫码配对后才能使用本地 API。同一时刻只允许一个实时会话。永久 Key 和证书私钥不会由静态文件路由提供，客户端只获得临时 Key。临时 Key 默认 180 秒过期，积分上限为体验时长 + 20（默认最多 35 积分），并发上限 1。准备阶段限时 45 秒；开始连接后等待首帧最多 20 秒；实际首帧出现后前后端分别计时，服务端额外留 1.5 秒供 SDK 清理。换衣不重置时限。上游停用失败会重试停用，未确认停止时不允许创建新会话。

按 Xmax 当前文档，X2.1 实时连接约按 1 积分/秒计费，实际扣费以 Xmax 控制台为准。限时与配额是节省额度的措施，不是对上游计费精确性的承诺。

## 预设素材

内置 8 张参考图：2 件上衣、2 件裤装、2 套服装、2 双鞋。上衣、裤装与套装取自 Xmax 官方示例参考素材，保留官方专用提示词；鞋履取自 DummyJSON 商品演示数据。它们用于本地体验，非有赞在售商品。页面也支持上传 JPG / PNG / WebP 自有商品图，最多 10 MB。

本地选择文件只生成浏览器预览；开始试衣或进行中的会话切换到该文件时，才经 SDK 上传到 Xmax 对象存储。上传得到的 URL 仅在本页面内存中缓存。刷新页面即丢失本次自定义衣橱，不做额外账号或云端衣橱。

参考文档：

- https://platform.xmaxai.com/docs/authentication
- https://github.com/Xmax-AI/XmaxSDK-Web
- https://dummyjson.com/products

## 交付状态

本次修正连接前提前计时的问题，输出层不再隐藏，默认采集降为约 720p、20 fps，上行码率上限 1600 kbps；保留 SDK 自动质量调整。页面提前加载 SDK，换图失败不再直接关闭仍有效的实时连接。停止操作最多等待 SDK 清理 5 秒后停用凭证。仅将阶段耗时和数值错误码记入 `.local/connection-events.jsonl`，不保存密钥或画面。实际网络速度和模型流畅度尚未验证。
